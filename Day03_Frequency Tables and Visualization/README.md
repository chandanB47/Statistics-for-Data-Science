# Day 03 — Frequency Tables and Visualization

**Estimated time:** 30–45 minutes  
**Main dataset:** `../datasets/customer_campaign_data.csv`

## Goal
Summarize categories with counts and percentages, then choose a useful chart.

## Key concepts
- A **frequency** is a count in a category.
- **Relative frequency** = category count ÷ total count.
- **Percentage** = relative frequency × 100.
- Use bar charts for categories and histograms for numerical distributions. A box plot summarizes median, quartiles, and potential outliers.
- Label axes and include units. Avoid 3D charts and misleading scales.

## Worked example
If 60 out of 300 records belong to one channel, its relative frequency is 60/300 = 0.20, or 20%.
